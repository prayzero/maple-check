## 날짜와 검증 메타데이터

- `coverageEnd`: 공지가 존재하는 마지막 수록일 2026-10-25. 미래 공지를 포함합니다.
- `observedThrough`: 확인일 전에 날짜가 지난 마지막 기록 2026-10-18.
- `announcedThrough`: 확인일에 아직 종료되지 않은 공지 중 마지막 날짜 2026-10-25.
- `asOf`: 기록 상태와 과거 결과 검증 기준일 2026-10-23.
- `status`: 기준일보다 이전은 `observed`, 당일은 `ongoing`, 이후는 `announced`. `observed`는 날짜가 지났다는 뜻이며, 공식 검증 여부는 별도 `officialVerified`로 구분합니다.
- `officialVerifiedAt`: 직접 공식 대조한 날짜 2026-10-23. 빌더만 다시 실행해서 이 값을 현재 날짜로 바꾸지 않습니다.
- `officialContinuousFrom`/`officialContinuousThrough`, `officialSampleDates`, 검증/미검증 건수: 실제 대조 범위를 구분합니다.
- `backtest.cutoffDate`: 마지막 종료 기록 2026-10-18. 미래 공지와 진행 당일은 완료된 결과로 평가하지 않습니다.

```bash
python -B tools/build_sunday_history.py --input sunday-history.json --as-of 2026-10-23 --output sunday-history.json
node tools/test_sunday_official.js

```

`test_sunday_official.js`는 Python도 실행합니다. `python`이 PATH에 없으면 `PYTHON` 환경 변수에 설치된 Python 실행 파일 경로를 지정합니다.
